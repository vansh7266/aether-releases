# Aether - downloads

Built apps for **Aether**, your personal AI that lives on your desktop. The source code is private;
only the finished apps are published here.

Install (it sets up the download for you):

```bash
brew install vansh7266/aether/aether          # macOS
```
```powershell
scoop bucket add aether https://github.com/vansh7266/scoop-aether
scoop install aether                           # Windows
```

Then: `aether setup`, `aether start`, and press Ctrl+Shift+Space.
